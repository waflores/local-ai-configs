# CMMI Level 5 Roadmap: Data-Driven LLM Inference Platform

## Goal

Transform this llama-swap configuration repository from a static documentation-only codebase into a data-driven, self-optimizing inference platform that enables AI agents to make intelligent, evidence-based decisions about model selection, configuration tuning, and performance optimization.

## Current Context & Assumptions

### What We Have (Foundation Layer)

- **Hardware**: NVIDIA RTX 5070 Max-Q (~8GB VRAM) + Intel Integrated Graphics (~23GB shared)
- **Models**: 22 GGUF models across various sizes (3B-27B parameters)
- **Configuration**: Complete llama-swap config.yaml with 29 model definitions
- **Documentation**: README.md, SKILL.md, AGENTS.md with role definitions
- **Integration Scripts**: llamastash integration patterns, inferhost configs

### What We're Missing (Operational Layer)

- **No benchmark results** - Cannot make data-driven decisions
- **No performance logs** - No visibility into actual runtime behavior
- **No error tracking** - Troubleshooting relies on guesswork
- **No configuration history** - Cannot track iteration progress
- **No automated testing** - Manual verification only

### CMMI ANALYSIS

| Capability | Current Level | Target Level | Gap |
|------------|---------------|--------------|-----|
| **Process Management** | 1 (Initial) | 5 (Optimizing) | 4 levels |
| **Configuration Management** | 2 (Repeatable) | 5 (Optimizing) | 3 levels |
| **Performance Measurement** | 1 (Initial) | 5 (Optimizing) | 4 levels |
| **Decision Making** | 1 (Initial) | 4 (Quantitatively Managed) | 3 levels |
| **Automation** | 1 (Initial) | 5 (Optimizing) | 4 levels |

**Current Overall Level: 1.5 (Ad Hoc)**

- Configuration exists but is not validated systematically
- No automated performance measurement
- Decisions made manually without data
- Error handling is reactive, not proactive

**Target Level: 5 (Optimizing)**

- All processes are quantitative and automated
- Continuous improvement based on metrics
- Self-optimizing configuration management
- Predictive performance modeling

## Architecture & Proposed Approach

**Three-Layer Architecture:**

1. **Foundation Layer** (Existing) - Static configuration and documentation
1. **Operational Layer** (Building) - Automated measurement, logging, validation
1. **Optimization Layer** (Future) - Self-tuning, predictive modeling, auto-configuration

**Implementation Strategy:**

- Build incrementally: measurement -> logging -> analysis -> automation -> optimization
- Each step produces artifacts that feed the next layer
- All code is testable from day one (TDD cycle)
- Every configuration change is logged and versioned

**File**: `llama-swap/run_benchmarks.py`

```python
#!/usr/bin/env python3
"""
llama-bench: Benchmark suite for llama-swap models
Tests all models and collects performance metrics
"""

import json
import subprocess
import time
import sys
from datetime import datetime
from pathlib import Path
from typing import Optional

TIMESTAMP = datetime.now().strftime("%Y%m%d_%H%M%S")
RESULTS_FILE = Path("/home/waflores/DevFolder/ai/local-config/benchmark_results.json")
CONFIG_FILE = Path("/home/waflores/DevFolder/ai/local-config/llama-swap/config.yaml")


def load_config():
    """Load llama-swap configuration."""
    import yaml

    with open(CONFIG_FILE) as f:
        return yaml.safe_load(f)


def load_results():
    """Load or create benchmark results file."""
    if RESULTS_FILE.exists():
        with open(RESULTS_FILE) as f:
            return json.load(f)
    return {
        "metadata": {
            "created": datetime.now().isoformat(),
            "config_file": str(CONFIG_FILE),
            "gpu_devices": ["CUDA0", "Vulkan0", "Vulkan1"],
        },
        "models": [],
        "configurations": [],
        "errors": [],
    }


def save_results(results):
    """Save benchmark results to file."""
    with open(RESULTS_FILE, "w") as f:
        json.dump(results, f, indent=2)


def check_health(config):
    """Check llama-swap health endpoint."""
    import requests

    try:
        response = requests.get("http://127.0.0.1:10001/health", timeout=5)
        if response.status_code == 200:
            return True, None
        return False, f"Health check failed: {response.status_code}"
    except Exception as e:
        return False, str(e)


def load_model(config, model_name, model_config):
    """Load a model and measure load time."""
    health_ok, _ = check_health(config)
    if not health_ok:
        print(f"Warning: llama-swap not running, starting...")
        subprocess.run(
            [
                "/home/waflores/bin/llama-swap",
                "--config",
                str(CONFIG_FILE),
                "--listen",
                "127.0.0.1:10001",
            ],
            capture_output=True,
        )
        time.sleep(5)
        health_ok, _ = check_health(config)
        if not health_ok:
            print(f"Error: Failed to start llama-swap")
            return False

    # Build command
    cmd = model_config["cmd"].replace(
        "${models_directory}", "/home/waflores/.lmstudio/models/lmstudio-community"
    )

    # Extract model path from command
    import re

    model_path_match = re.search(
        r"--model (.+?)(?:\s+--n-gpu-layers|--threads|--flash-attn|$)", cmd
    )
    if not model_path_match:
        print(f"Error: Could not extract model path for {model_name}")
        return False

    model_path = model_path_match.group(1).strip()

    # Check if model exists
    if not Path(model_path).exists():
        print(f"Error: Model not found: {model_path}")
        return False

    print(f"Loading {model_name} from {model_path}...")

    # Load model
    load_result = subprocess.run(
        [
            "curl",
            "-X",
            "POST",
            "http://127.0.0.1:10001/v1/models",
            "-H",
            "Content-Type: application/json",
            "-d",
            json.dumps({"name": model_name, "path": model_path, "ttl": 3600}),
        ],
        capture_output=True,
        text=True,
    )

    if "error" in load_result.stdout.lower():
        print(f"Error: Failed to load model: {load_result.stdout}")
        return False

    # Measure load time
    start = time.time()
    subprocess.run(["sleep", "3"], capture_output=True)
    load_time = time.time() - start

    print(f"Loaded {model_name} in {load_time:.2f}s")
    return True


def unload_model(config, model_name):
    """Unload a model and measure unload time."""
    health_ok, _ = check_health(config)
    if not health_ok:
        return False, 0

    print(f"Unloading {model_name}...")

    start = time.time()
    subprocess.run(
        [
            "curl",
            "-X",
            "DELETE",
            f"http://127.0.0.1:10001/v1/models/{model_name.replace(' ', '-')}",
        ],
        capture_output=True,
    )
    subprocess.run(["sleep", "2"], capture_output=True)
    unload_time = time.time() - start

    print(f"Unloaded {model_name} in {unload_time:.2f}s")
    return True, unload_time


def run_inference_benchmark(config, model_name, model_config):
    """Run inference benchmark and measure tokens/sec."""
    health_ok, _ = check_health(config)
    if not health_ok:
        return False, 0

    prompt = "Count from 1 to 100"
    print(f"Running inference benchmark for {model_name}...")

    start = time.time()
    result = subprocess.run(
        [
            "curl",
            "-X",
            "POST",
            "http://127.0.0.1:10001/v1/chat/completions",
            "-H",
            "Content-Type: application/json",
            "-d",
            json.dumps(
                {
                    "model": model_name,
                    "messages": [{"role": "user", "content": prompt}],
                    "max_tokens": 50,
                    "temperature": 0,
                }
            ),
        ],
        capture_output=True,
        text=True,
    )

    generation_time = time.time() - start

    # Count tokens in response
    if "content" in result.json():
        tokens = len(result.json()["content"].split())
        tokens_per_second = tokens / generation_time if generation_time > 0 else 0
    else:
        tokens_per_second = 0

    print(f"Inference: {tokens_per_second:.2f} tokens/sec")
    return True, tokens_per_second


def run_benchmarks(config, models, run_inference=False):
    """Run benchmarks for all models."""
    results = load_results()

    for model_name in models:
        if model_name not in config["models"]:
            print(f"Skipping {model_name} (not in config)")
            continue

        model_config = config["models"][model_name]
        print(f"\n{'=' * 60}")
        print(f"BENCHMARK: {model_name}")
        print(f"{'=' * 60}")

        # Load model
        if not load_model(config, model_name, model_config):
            continue

        # Get VRAM usage
        import requests

        try:
            response = requests.get("http://127.0.0.1:10001/v1/models", timeout=5)
            if response.status_code == 200:
                models_response = response.json()
                for m in models_response.get("data", []):
                    if m["id"] == model_name:
                        vram_mb = m.get("size_in_bytes", 0) / (1024 * 1024)
                        print(f"VRAM Usage: {vram_mb:.2f} MB")
                        break
        except Exception as e:
            print(f"Could not get VRAM usage: {e}")

        # Run inference benchmark if requested
        if run_inference:
            success, tokens_per_second = run_inference_benchmark(
                config, model_name, model_config
            )
            if success:
                print(f"Inference Speed: {tokens_per_second:.2f} tokens/sec")

        # Unload model
        unload_model(config, model_name)

    return results


def main():
    """Main entry point."""
    import argparse

    parser = argparse.ArgumentParser(description="Benchmark llama-swap models")
    parser.add_argument("--model", type=str, help="Single model to benchmark")
    parser.add_argument("--all", action="store_true", help="Benchmark all models")
    parser.add_argument(
        "--inference", action="store_true", help="Run inference benchmarks"
    )
    parser.add_argument("--output", type=str, help="Output JSON file")

    args = parser.parse_args()

    # Load config
    config = load_config()
    models = list(config["groups"]["swappable"]["members"].keys())

    if args.all:
        models = models
    elif args.model:
        if args.model in config["models"]:
            models = [args.model]
        else:
            print(f"Error: Model not found: {args.model}")
            sys.exit(1)
    else:
        print("Error: Specify --model or --all")
        sys.exit(1)

    # Run benchmarks
    results = run_benchmarks(config, models, args.inference)

    # Save results
    save_results(results)
    print(f"\nResults saved to {RESULTS_FILE}")

    if args.output:
        with open(args.output, "w") as f:
            json.dump(results, f, indent=2)
        print(f"Results also saved to {args.output}")


if __name__ == "__main__":
    main()
```

```markdown
Common errors and their solutions for llama-swap.

### "CUDA out of memory"

**Error Message**:
```

CUDA out of memory. Tried to allocate X MiB

````

**Cause**: Model or context size exceeds available VRAM

**Solutions**:
1. Reduce context size in model config
2. Enable model swapping
3. Use Vulkan backend for swapped models
4. Reduce quantization (Q4_K_M -> Q3_K_M)
````

```python
"""
Config Validator: Validates llama-swap configuration files
Checks syntax, model existence, device assignments, and health
"""

import json
import os
import sys
import yaml
from pathlib import Path
from typing import Optional, List, Tuple

CONFIG_FILE = Path("/home/waflores/DevFolder/ai/local-config/llama-swap/config.yaml")
MODELS_DIR = Path("/home/waflores/.lmstudio/models/lmstudio-community")


class ConfigValidator:
    """Validates llama-swap configuration."""

    def __init__(self, config_path):
        self.config_path = config_path
        self.errors = []
        self.warnings = []
        self.info = []

    def validate(self):
        """Run all validation checks."""
        self._check_file_exists()
        self._check_yaml_syntax()
        self._check_global_settings()
        self._check_models()
        self._check_device_assignments()
        self._check_health_endpoint()

        is_valid = len(self.errors) == 0
        messages = self.errors + self.warnings + self.info
        return is_valid, messages

    def _check_file_exists(self):
        """Check config file exists."""
        if not self.config_path.exists():
            self.errors.append(f"Config file not found: {self.config_path}")
        else:
            self.info.append(f"Config file exists: {self.config_path}")

    def _check_yaml_syntax(self):
        """Check YAML syntax."""
        try:
            with open(self.config_path) as f:
                config = yaml.safe_load(f)
            self.info.append("YAML syntax is valid")
        except yaml.YAMLError as e:
            self.errors.append(f"YAML syntax error: {e}")

    def _check_global_settings(self):
        """Check global configuration settings."""
        try:
            with open(self.config_path) as f:
                config = yaml.safe_load(f)

            # Check required global settings
            if "globalTTL" not in config:
                self.warnings.append(
                    "globalTTL not set (models will not unload automatically)"
                )

            if "healthCheckTimeout" not in config:
                self.warnings.append("healthCheckTimeout not set (default: 60s)")

            if "logLevel" not in config:
                self.warnings.append("logLevel not set (default: info)")

            # Check models_directory
            if "models" in config:
                models_directory = (
                    config["models"]
                    .get(list(config["models"].keys())[0], {})
                    .get("cmd", "")
                )

                if "models_directory" in config.get("macros", {}):
                    models_dir = config["macros"]["models_directory"]
                    self.info(f"Models directory: {models_dir}")

                    # Check if directory exists
                    if Path(models_dir).exists():
                        self.info(f"Models directory exists: {models_dir}")
                    else:
                        self.warnings(f"Models directory not found: {models_dir}")

        except Exception as e:
            self.errors.append(f"Error checking global settings: {e}")

    def _check_models(self):
        """Check model configurations."""
        try:
            with open(self.config_path) as f:
                config = yaml.safe_load(f)

            if "models" not in config:
                self.warnings.append("No models defined in config")
                return

            models_checked = 0
            for model_name, model_config in config["models"].items():
                models_checked += 1

                # Check if model has a command
                if "cmd" not in model_config:
                    self.errors.append(f"Model '{model_name}' missing 'cmd' field")
                    continue

                # Extract model path from command
                cmd = model_config["cmd"]
                import re

                model_path_match = re.search(
                    r"--model (.+?)(?:\s+--n-gpu-layers|--threads|--flash-attn|$)", cmd
                )

                if model_path_match:
                    model_path = model_path_match.group(1).strip()

                    # Check if model file exists
                    if Path(model_path).exists():
                        self.info(f"Model exists: {model_name}")
                    else:
                        self.warnings(f"Model path may not exist: {model_path}")

                    # Check quantization level
                    if "Q4_K_M" in model_path:
                        self.info(f"  Quantization: Q4_K_M")
                    elif "Q3_K" in model_path:
                        self.info(f"  Quantization: Q3_K")
                    elif "Q5_K" in model_path:
                        self.info(f"  Quantization: Q5_K")
                else:
                    self.warnings(f"Could not extract model path for: {model_name}")

            self.info(f"Total models checked: {models_checked}")

        except Exception as e:
            self.errors.append(f"Error checking models: {e}")

    def _check_device_assignments(self):
        """Check device assignments."""
        try:
            with open(self.config_path) as f:
                config = yaml.safe_load(f)

            if "models" not in config:
                return

            # Check for device assignments
            for model_name, model_config in config["models"].items():
                if "cmd" not in model_config:
                    continue

                cmd = model_config["cmd"]

                # Check device assignment
                if "CUDA0" in cmd or "Vulkan0" in cmd or "Vulkan1" in cmd:
                    self.info(f"Model {model_name} has device assignment")
                else:
                    self.warnings(
                        f"Model {model_name} may not have explicit device assignment"
                    )

        except Exception as e:
            self.errors.append(f"Error checking device assignments: {e}")

    def _check_health_endpoint(self):
        """Check llama-swap health endpoint (requires server running)."""
        try:
            import requests

            # Try to connect to health endpoint
            response = requests.get("http://127.0.0.1:10001/health", timeout=2)

            if response.status_code == 200:
                health_data = response.json()
                self.info(
                    f"Health endpoint responding: {health_data.get('status', 'ok')}"
                )

                # Check loaded models
                if "models" in health_data:
                    loaded_count = len(health_data["models"])
                    self.info(f"{loaded_count} model(s) currently loaded")
            else:
                self.warnings(
                    "Health endpoint not responding (server may not be running)"
                )

        except requests.exceptions.ConnectionError:
            self.warnings(
                "Cannot connect to health endpoint (server may not be running)"
            )
        except Exception as e:
            self.warnings(f"Health check error: {e}")


def main():
    """Main entry point."""
    import argparse

    parser = argparse.ArgumentParser(description="Validate llama-swap configuration")
    parser.add_argument("--config", type=str, help="Path to config file")
    parser.add_argument("--verbose", "-v", action="store_true", help="Verbose output")

    args = parser.parse_args()

    config_path = Path(args.config) if args.config else CONFIG_FILE

    if not config_path.exists():

if __name__ == "__main__":
```

```python
"""
Performance Logger: Logs and tracks llama-swap performance metrics
"""

import json
import time
from datetime import datetime
from pathlib import Path
from typing import Optional, Dict, List

LOGS_FILE = Path("/home/waflores/DevFolder/ai/local-config/performance_logs.json")


class PerformanceLogger:
    """Logs and tracks performance metrics."""

    def __init__(self):
        self.logs = []
        self._ensure_logs_file()

    def _ensure_logs_file(self):
        """Ensure logs file exists."""
        if not LOGS_FILE.exists():
            self.logs = []

    def log_load(self, model_name, load_time_seconds, vram_mb=None):
        """Log model load event."""
        entry = {
            "timestamp": datetime.now().isoformat(),
            "event": "load",
            "model": model_name,
            "load_time_seconds": round(load_time_seconds, 3),
            "vram_mb": round(vram_mb, 2) if vram_mb else None,
            "context_size": None,
            "temperature": None,
        }
        self.logs.append(entry)
        self._save()
        return entry

    def log_unload(self, model_name, unload_time_seconds):
        """Log model unload event."""
        entry = {
            "timestamp": datetime.now().isoformat(),
            "event": "unload",
            "model": model_name,
            "unload_time_seconds": round(unload_time_seconds, 3),
        }
        self.logs.append(entry)
        self._save()
        return entry

    def log_swap(self, model_from, model_to, swap_time_seconds):
        """Log model swap event."""
        entry = {
            "timestamp": datetime.now().isoformat(),
            "event": "swap",
            "model_from": model_from,
            "model_to": model_to,
            "swap_time_seconds": round(swap_time_seconds, 3),
        }
        self.logs.append(entry)
        self._save()
        return entry

    def log_inference(self, model_name, tokens, generation_time_seconds):
        """Log inference event."""
        entry = {
            "timestamp": datetime.now().isoformat(),
            "event": "inference",
            "model": model_name,
            "tokens": tokens,
            "tokens_per_second": round(tokens / generation_time_seconds, 2)
            if generation_time_seconds > 0
            else 0,
            "generation_time_seconds": round(generation_time_seconds, 3),
        }
        self.logs.append(entry)
        self._save()
        return entry

    def log_error(self, model_name, error_message):
        """Log error event."""
        entry = {
            "timestamp": datetime.now().isoformat(),
            "event": "error",
            "model": model_name,
            "error_message": error_message,
        }
        self.logs.append(entry)
        self._save()
        return entry

    def _save(self):
        """Save logs to file."""
        with open(LOGS_FILE, "w") as f:
            json.dump(self.logs, f, indent=2)

    def get_stats(self):
        """Get performance statistics."""
        if not self.logs:
            return {"error": "No logs available"}

        stats = {
            "total_events": len(self.logs),
            "load_events": sum(1 for e in self.logs if e["event"] == "load"),
            "unload_events": sum(1 for e in self.logs if e["event"] == "unload"),
            "swap_events": sum(1 for e in self.logs if e["event"] == "swap"),
            "inference_events": sum(1 for e in self.logs if e["event"] == "inference"),
            "error_events": sum(1 for e in self.logs if e["event"] == "error"),
            # Average load time
            "avg_load_time_seconds": None,
            "avg_unload_time_seconds": None,
            "avg_swap_time_seconds": None,
            "avg_tokens_per_second": None,
            # Model-specific stats
            "model_stats": {},
        }

        # Calculate averages
        load_times = [
            e["load_time_seconds"]
            for e in self.logs
            if e["event"] == "load" and e.get("load_time_seconds")
        ]
        unload_times = [
            e["unload_time_seconds"]
            for e in self.logs
            if e["event"] == "unload" and e.get("unload_time_seconds")
        ]
        swap_times = [
            e["swap_time_seconds"]
            for e in self.logs
            if e["event"] == "swap" and e.get("swap_time_seconds")
        ]
        tps_values = [
            e.get("tokens_per_second")
            for e in self.logs
            if e["event"] == "inference" and e.get("tokens_per_second")
        ]

        if load_times:
            stats["avg_load_time_seconds"] = round(sum(load_times) / len(load_times), 3)
        if unload_times:
            stats["avg_unload_time_seconds"] = round(
                sum(unload_times) / len(unload_times), 3
            )
        if swap_times:
            stats["avg_swap_time_seconds"] = round(sum(swap_times) / len(swap_times), 3)
        if tps_values:
            stats["avg_tokens_per_second"] = round(sum(tps_values) / len(tps_values), 2)

        # Model-specific stats
        for model_name in set(e["model"] for e in self.logs):
            model_logs = [e for e in self.logs if e["model"] == model_name]
            model_load_times = [
                e["load_time_seconds"]
                for e in model_logs
                if e["event"] == "load" and e.get("load_time_seconds")
            ]

            if model_load_times:
                stats["model_stats"][model_name] = {
                    "total_loads": len(model_load_times),
                    "avg_load_time_seconds": round(
                        sum(model_load_times) / len(model_load_times), 3
                    ),
                }

        return stats

    def get_logs_for_model(self, model_name):
        """Get all logs for a specific model."""
        return [e for e in self.logs if e["model"] == model_name]

    def get_recent_logs(self, limit=10):
        """Get most recent logs."""
        return self.logs[-limit:] if len(self.logs) >= limit else self.logs[:]


def main():

    import argparse

    parser = argparse.ArgumentParser(description="Log llama-swap performance metrics")
```

```python
                self._log_health("error", result)
                return result

        except requests.exceptions.ConnectionError:

            result["error"] = "Cannot connect to health endpoint"
            self._log_health("error", result)
            return result

            result["status"] = "error"
            result["error"] = str(e)
            self._log_health("error", result)

    def check_vram_usage(self):
        """Check VRAM usage."""
        result = {
            "timestamp": datetime.now().isoformat(),
            "status": "unknown",
            "error": None,
        }

        try:
            # Check GPU memory
            output = subprocess.run(
                ["nvidia-smi", "--query-gpu=memory_total,memory_free", "--format=csv"],
                capture_output=True,
                text=True,
                timeout=5,
            )

            if output.returncode == 0:
                lines = output.stdout.strip().split("\n")
                for line in lines:
                    parts = line.strip().split(",")
                    if len(parts) == 2:
                        total_mb = int(parts[0])
                        free_mb = int(parts[1])
                        used_mb = total_mb - free_mb
                        usage_percent = (
                            (used_mb / total_mb) * 100 if total_mb > 0 else 0
                        )

                        result["vram_total_mb"] = total_mb
                        result["vram_free_mb"] = free_mb
                        result["vram_used_mb"] = used_mb
                        result["vram_usage_percent"] = round(usage_percent, 2)

                        # Alert if usage is high
                        if usage_percent > 80:
                            result["status"] = "warning"
                            result["error"] = f"High VRAM usage: {usage_percent:.1f}%"
                        elif usage_percent > 90:
                            result["status"] = "critical"
                            result["error"] = (
                                f"Critical VRAM usage: {usage_percent:.1f}%"
                            )
                        else:
                            result["status"] = "ok"

                        return result
            else:
                result["status"] = "error"
                result["error"] = "Failed to get VRAM usage"
                self._log_health("error", result)
                return result

            result["status"] = "error"
            result["error"] = str(e)
            self._log_health("error", result)
            return result

        """Get health summary."""

            return {"error": "No health logs available"}

        summary = {
            "total_checks": len(self.health_logs),
            "ok_checks": sum(1 for e in self.health_logs if e.get("status") == "ok"),
            "warning_checks": sum(
                1 for e in self.health_logs if e.get("status") == "warning"
            ),
            "error_checks": sum(
                1 for e in self.health_logs if e.get("status") == "error"
            ),
            "last_check": self.health_logs[-1]["timestamp"]
            if self.health_logs
            else None,
            "last_status": self.health_logs[-1].get("status")
            if self.health_logs
            else None,
            "last_error": self.health_logs[-1].get("error")
            if self.health_logs
            else None,
        }

        return summary

    def get_alerts(self):
        """Get recent alerts."""
        alerts = []

        for log in self.health_logs[-10:]:  # Last 10 checks
            if log.get("status") in ["warning", "critical", "error"]:
                alerts.append(
                    {
                        "timestamp": log["timestamp"],
                        "status": log["status"],
                        "error": log.get("error"),
                    }
                )

        return alerts


def main():
```

```python
#!/usr/bin/env python3
"""
Configuration Optimizer: Analyzes and suggests configuration improvements
"""

import json
import yaml
from pathlib import Path
from typing import Optional, Dict, List, Tuple

CONFIG_FILE = Path("/home/waflores/DevFolder/ai/local-config/llama-swap/config.yaml")
BENCHMARK_RESULTS = Path(
    "/home/waflores/DevFolder/ai/local-config/benchmark_results.json"
)
VERSIONS_FILE = Path("/home/waflores/DevFolder/ai/local-config/VERSIONS.md")


class ConfigOptimizer:
    """Analyzes and optimizes llama-swap configuration."""

    def __init__(self, config_file):
        self.config_file = config_file
        self.config = self._load_config()

    def _load_config(self):
        """Load configuration file."""
        with open(self.config_file) as f:
            return yaml.safe_load(f)

    def analyze_config(self):
        """Analyze current configuration."""
        analysis = {
            "config_file": str(self.config_file),
            "total_models": len(self.config.get("models", {})),
            "swappable_models": len(
                self.config.get("groups", {}).get("swappable", {}).get("members", {})
            ),
            "models_by_size": {},
            "models_by_device": {},
            "recommendations": [],
            "warnings": [],
            "info": [],
        }

        # Analyze models
        for model_name, model_config in self.config.get("models", {}).items():
            # Extract context size
            ctx_size = model_config.get("macros", {}).get("ctxSize", "unknown")
            try:
                ctx_size_int = int(ctx_size) if str(ctx_size) != "unknown" else 0
            except ValueError, TypeError:
                ctx_size_int = 0

            # Categorize by size
            if ctx_size_int > 100000:
                size_category = "large"
            elif ctx_size_int > 50000:
                size_category = "medium"
            else:
                size_category = "small"

            if size_category not in analysis["models_by_size"]:
                analysis["models_by_size"][size_category] = []
            analysis["models_by_size"][size_category].append(model_name)

            # Categorize by parameters (estimated from name)
            if "7B" in model_name or "4B" in model_name or "3B" in model_name:
                param_category = "small"
            elif "8B" in model_name or "9B" in model_name:
                param_category = "medium"
            elif "13B" in model_name or "14B" in model_name:
                param_category = "large"
            elif "24B" in model_name or "27B" in model_name:
                param_category = "xlarge"
            else:
                param_category = "unknown"

            if param_category not in analysis["models_by_size"]:
                analysis["models_by_size"][param_category] = []
            analysis["models_by_size"][param_category].append(model_name)

        # Generate recommendations
        self._generate_recommendations(analysis)

        return analysis

    def _generate_recommendations(self, analysis):
        """Generate optimization recommendations."""
        recommendations = []
        warnings = []

        # Check for models with very large context sizes
        for model_name, model_config in self.config.get("models", {}).items():
            ctx_size = model_config.get("macros", {}).get("ctxSize", "unknown")
            try:
                ctx_size_int = int(ctx_size) if str(ctx_size) != "unknown" else 0

                if ctx_size_int > 200000:
                    recommendations.append(
                        {
                            "type": "context_size_optimization",
                            "model": model_name,
                            "current": f"{ctx_size_int} tokens",
                            "suggestion": "Consider reducing to 131072 tokens for better VRAM efficiency",
                            "reason": "Large context sizes consume significant VRAM",
                        }
                    )
            except ValueError, TypeError:
                pass

        # Check for models without flash-attn
        for model_name, model_config in self.config.get("models", {}).items():
            cmd = model_config.get("cmd", "")
            if "flash-attn" not in cmd:
                warnings.append(
                    {
                        "type": "flash_attn_missing",
                        "model": model_name,
                        "suggestion": "Enable flash-attn for better performance",
                        "reason": "Flash attention improves inference speed by ~2x",
                    }
                )

        # Check for models without device assignment
        for model_name, model_config in self.config.get("models", {}).items():
            cmd = model_config.get("cmd", "")
            if "CUDA0" not in cmd and "Vulkan0" not in cmd:
                warnings.append(
                    {
                        "type": "device_assignment_missing",
                        "model": model_name,
                        "suggestion": "Add explicit device assignment (CUDA0 or Vulkan0)",
                        "reason": "Explicit device assignment ensures consistent behavior",
                    }
                )

        # Check global settings
        if "globalTTL" not in self.config:
            recommendations.append(
                {
                    "type": "global_ttl",
                    "current": "not set",
                    "suggestion": "Set globalTTL to 300 for automatic model unloading",
                    "reason": "Automatic unloading prevents VRAM exhaustion",
                }
            )

        analysis["recommendations"] = recommendations
        analysis["warnings"] = warnings

        return analysis

    def suggest_optimizations(self):
        """Suggest specific optimization changes."""
        suggestions = {
            "context_size_optimizations": [],
            "quantization_suggestions": [],
            "device_balancing": [],
            "performance_improvements": [],
        }

        # Suggest context size optimizations
        for model_name, model_config in self.config.get("models", {}).items():
            ctx_size = model_config.get("macros", {}).get("ctxSize", "unknown")
            try:
                ctx_size_int = int(ctx_size) if str(ctx_size) != "unknown" else 0

                if ctx_size_int > 150000:
                    suggestions["context_size_optimizations"].append(
                        {
                            "model": model_name,
                            "current": ctx_size_int,
                            "suggested": 131072,
                            "reason": "Reduce for better VRAM efficiency",
                        }
                    )
            except ValueError, TypeError:
                pass

        # Suggest quantization improvements
        for model_name, model_config in self.config.get("models", {}).items():
            cmd = model_config.get("cmd", "")
            if "Q8_0" in cmd:
                suggestions["quantization_suggestions"].append(
                    {
                        "model": model_name,
                        "current": "Q8_0",
                        "suggested": "Q4_K_M",
                        "reason": "Q4_K_M provides better size/quality balance",
                    }
                )

        # Suggest device balancing
        cuda_models = []
        vulkan_models = []

        for model_name, model_config in self.config.get("models", {}).items():
            cmd = model_config.get("cmd", "")
            if "CUDA0" in cmd:
                cuda_models.append(model_name)
            elif "Vulkan0" in cmd:
                vulkan_models.append(model_name)

        if len(cuda_models) > 1:
            suggestions["device_balancing"].append(
                {
                    "type": "consolidate_to_cuda",
                    "current_cuda_models": cuda_models,
                    "suggestion": "Keep 1-2 models on CUDA0, move others to Vulkan0",
                    "reason": "Concentrating active models on one GPU improves performance",
                }
            )

        return suggestions

    def generate_optimized_config(self):
        """Generate an optimized configuration."""
        optimized = self.config.copy()

        # Apply optimizations
        suggestions = self.suggest_optimizations()

        # Apply context size optimizations
        for opt in suggestions["context_size_optimizations"]:
            model_name = opt["model"]
            new_ctx_size = str(opt["suggested"])

            if model_name in optimized["models"]:
                optimized["models"][model_name]["macros"]["ctxSize"] = new_ctx_size

        # Apply quantization suggestions
        for opt in suggestions["quantization_suggestions"]:
            model_name = opt["model"]

            if model_name in optimized["models"]:
                cmd = optimized["models"][model_name]["cmd"]
                if f"-{opt['current']}" in cmd:
                    new_cmd = cmd.replace(f"-{opt['current']}", f"-{opt['suggested']}")
                    optimized["models"][model_name]["cmd"] = new_cmd

        # Apply device balancing
        if suggestions["device_balancing"]:
            # Keep first 2 models on CUDA0, move rest to Vulkan0
            cuda_models = list(optimized["models"].keys())[:2]
            vulkan_models = list(optimized["models"].keys())[2:]

            for model_name in vulkan_models:
                if model_name in optimized["models"]:
                    cmd = optimized["models"][model_name]["cmd"]
                    if "CUDA0" in cmd:
                        optimized["models"][model_name]["cmd"] = cmd.replace(
                            "CUDA0", "Vulkan0"
                        )

            optimized["models"] = dict(
                list(optimized["models"].items())
                + [(k, v) for k, v in optimized["models"].items() if k in cuda_models]
            )

        return optimized

    def save_optimized_config(self, optimized_config, output_file):
        """Save optimized configuration to file."""
        try:
            with open(output_file, "w") as f:
                yaml.dump(
                    optimized_config, f, default_flow_style=False, sort_keys=False
                )
            return True
        except Exception as e:
            print(f"Error saving optimized config: {e}")
            return False


def main():
    """Main entry point."""
    import argparse

    parser = argparse.ArgumentParser(description="Optimize llama-swap configuration")
    parser.add_argument("--analyze", action="store_true", help="Analyze current config")
    parser.add_argument("--suggest", action="store_true", help="Suggest optimizations")
    parser.add_argument(
        "--optimize", action="store_true", help="Generate optimized config"

    parser.add_argument("--output", type=str, help="Output file for optimized config")
    parser.add_argument("--verbose", "-v", action="store_true", help="Verbose output")

    args = parser.parse_args()

    optimizer = ConfigOptimizer(CONFIG_FILE)

    if args.analyze:

                print(f"\nOptimized config saved to: {args.output}")
            else:
                print(f"\nFailed to save optimized config")

    else:
        print("Usage: python3 config_optimizer.py [--analyze | --suggest | --optimize]")


if __name__ == "__main__":
    main()
```

## Risks, Tradeoffs, and Open Questions

### Risks

1. **Benchmark Script Complexity**: Full benchmark suite may be complex to maintain

   - **Mitigation**: Start with minimal viable benchmark, add features incrementally
   - **Tradeoff**: Simpler benchmarks may miss edge cases

1. **Performance Logger Data Volume**: Large number of logs may impact performance

   - **Mitigation**: Implement log rotation, keep only last 1000 entries
   - **Tradeoff**: May lose historical data for long-term analysis

1. **Configuration Optimizer May Suggest Unsafe Changes**: Automated optimizations could break configurations

   - **Mitigation**: Always require manual review before applying optimizations
   - **Tradeoff**: Slower optimization cycle, less automation

1. **Health Monitor May Cause Resource Contention**: Frequent health checks may impact performance

   - **Mitigation**: Default to 60s interval, allow user to adjust
   - **Tradeoff**: Less frequent checks may miss transient issues

### Tradeoffs

1. **Manual vs. Automated Optimization**:

   - **Manual**: More control, slower iteration
   - **Automated**: Faster, risk of breaking configs
   - **Decision**: Start manual, add automation as trust builds

1. **Comprehensive vs. Minimal Benchmarking**:

   - **Comprehensive**: More data, longer run times
   - **Minimal**: Faster, less data
   - **Decision**: Start minimal, add tests as needed

1. **Local vs. Remote Monitoring**:

   - **Local**: Faster, more accurate
   - **Remote**: Centralized, may add latency
   - **Decision**: Keep local for now, add remote later if needed

### Open Questions

1. **Benchmark Suite Scope**: Should we include all models or focus on high-priority ones?

   - **Recommendation**: Start with top 5 models by usage frequency

1. **Optimization Automation Level**: How much automation for config changes?

   - **Recommendation**: Manual approval required for all changes initially

1. **Data Retention Policy**: How long to keep performance logs?

   - **Recommendation**: Keep 90 days, then archive to cold storage

1. **Alerting Mechanism**: How to notify of issues?

   - **Recommendation**: Start with file-based alerts, add email/Slack later

1. **Integration with CI/CD**: Should benchmarking be part of CI pipeline?

   - **Recommendation**: Yes, but make it optional initially
