# .agents

## Purpose

The `.agents` folder is the **intent layer** for this LLM manager and llama-swap
configuration project. It contains AI agent definitions and project-specific
configuration instructions for AI coding assistants.

## Structure

- `agents/`: AI agent definitions and instructions for configuration tasks
- `config.json`: Machine-readable project authority
- `README.md`: This file
