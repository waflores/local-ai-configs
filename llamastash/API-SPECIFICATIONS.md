"# API Specifications\n\nThis document documents all available API endpoints for the LlamaStash + llama-swap integration.\n\n## LlamaStash Control Plane (JSON-RPC)\n\n**Base URL:** `http://127.0.0.1:48134`\n\n**Authentication:** Bearer token (stored in `$XDG_STATE_HOME/llamastash/runtime.json`)\n\n### Endpoints\n\n#### `/status`\n\nGet daemon status.\n\n**Request:** `POST /rpc` with `{"jsonrpc":"2.0","method":"status","id":1}`\n\n**Response:**\n\n```json\n{\n  \"jsonrpc\": \"2.0\",\n  \"result\": {\n    \"proxy\": {\n      \"enabled\": true,\n      \"listen\": \"127.0.0.1:11435\",\n      \"status\": \"listening\"\n    },\n    \"external\": [\n      {\n        \"pid\": 132604,\n        \"port\": 10001,\n        \"model_path\": \"/home/waflores/.lmstudio/models/lmstudio-community/Qwen3.5-9B-GGUF/Qwen3.5-9B-Q4_K_M.gguf\"\n      }\n    ]\n  },\n  \"id\": 1\n}\n```\n\n#### `/health`\n\nHealth check.\n\n**Request:** `GET /health`\n\n**Response:**\n\n```json\n{\"status\":\"ok\"}\n```\n\n### Available Methods\n\n| Method | Description |\n|--------|-------------|\n| `status` | Get daemon status |\n| `list` | List models |\n| `start_model` | Start a model |\n| `stop_model` | Stop a model |\n| `pull` | Pull a model (v2) |\n| `init` | Initialize (v2) |\n| `doctor` | Run diagnostics (v2) |\n| `capabilities` | Get supported methods |\n\n## LlamaStash Proxy (OpenAI-Compatible)\n\n**Base URL:** `http://127.0.0.1:11435`\n\n**Authentication:** None (loopback-only)\n\n### Endpoints\n\n#### `/health`\n\nHealth
